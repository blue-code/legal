FAQ

Can Nowbox turn on Focus / Do Not Disturb for me?
No app can — iOS does not allow it. Settings › “Hook up Focus mode” shows the three-step Shortcuts automation that connects a block start to a Focus, which you set up once.
왜 계획한 일이 다 안 들어가나요?
일부러 그렇습니다. 하루에 들어가지 않는 일감은 억지로 압축하지 않고 '오늘 못 담음'으로 보여줍니다. 예상 시간을 줄이거나 내일로 미루세요.
I bought Pro but it isn't active on my new phone.
Settings › Restore purchase. Pro is a one-time purchase tied to your Apple Account.
Is my data backed up?
Not in this version — everything is stored only on the device, and there is no server. Use Settings › Export my data for a JSON copy. iCloud sync is planned for a later update.
알림이 오지 않아요.
iOS 설정 › 알림 › Nowbox 에서 알림이 켜져 있는지 확인하세요. 블록 전환 알림은 계획을 확정할 때 미리 예약됩니다.
