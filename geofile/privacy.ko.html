GeoFile 개인정보처리방침

GeoFile은 개인정보를 수집·저장·전송하지 않습니다. 인터넷 연결 없이 동작합니다.

1. 수집하는 정보

없습니다. 회원 가입·로그인·분석 도구·광고가 없고, 앱은 인터넷에 연결하지 않습니다.

2. GIS 파일

앱은 사용자가 연 SHP·GeoJSON·KML·ZIP 파일만 읽습니다. 원본 파일은 바꾸지 않습니다. 파일은 모두 사용자 PC 안에서 처리하고(GIS 처리는 같은 PC의 별도 프로세스에서 합니다) 어디에도 올리지 않습니다.

변환한 파일, CSV, 지도 이미지, 변환 보고서는 사용자가 고른 위치에만 저장됩니다. ZIP은 사용자 PC의 임시 폴더에 풀며, 앱을 끝낼 때 지웁니다.

3. 구매와 체험판

구매와 무료 체험은 Microsoft Store가 처리합니다. 결제·계정 정보는 Microsoft가 처리하며 개발자는 받지 않습니다. Microsoft 개인정보처리방침

4. 기기에 저장하는 정보

다음은 사용자 PC의 %LOCALAPPDATA%\GeoFileToolkit\에만 저장됩니다.

  • settings.json: 화면 언어, 테마, 지도 표시 좌표계, 단위, 기본 출력 설정, 마지막 출력 폴더
  • recent.json: 최근 연 파일 경로
  • presets.json: 사용자가 저장한 변환 프리셋

Windows 임시 폴더(%TEMP%\GeoFileToolkit\)의 작업 파일은 앱을 끝낼 때 지웁니다. 이 정보는 어디로도 보내지 않습니다.
