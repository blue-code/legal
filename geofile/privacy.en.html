GeoFile Privacy Policy

GeoFile does not collect, store or transmit personal information. It works entirely offline.

1. Information collected

None. There is no sign-up, login, analytics or advertising, and the app does not connect to the internet.

2. GIS files

The app only reads the Shapefile, GeoJSON, KML and ZIP files the user opens. Original files are never modified. Files are processed entirely on the user's PC — GIS processing runs in a separate process on the same PC — and are never uploaded.

Converted files, CSV exports, map images and conversion reports are written only to the location the user chooses. A ZIP archive is extracted into a temporary folder on the user's PC, which is deleted when the app exits.

3. Purchases and trials

Purchases and free trials are handled by the Microsoft Store. Payment and account data are processed by Microsoft and are not received by the developer. Microsoft Privacy Statement

4. Local storage

The following are stored only on the user's PC under %LOCALAPPDATA%\GeoFileToolkit\:

  • settings.json: display language, theme, display coordinate system, units, default output options and the last output folder
  • recent.json: recently opened file paths
  • presets.json: conversion presets the user saves

Temporary working files under the Windows temporary folder (%TEMP%\GeoFileToolkit\) are deleted when the app exits. None of this is sent anywhere.
