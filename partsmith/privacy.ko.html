Partsmith 개인정보처리방침

Partsmith 개발자는 개인정보를 수집하지 않습니다. 사용자가 앱 안 AI 채팅을 켜면, 입력한 내용은 사용자 본인의 Anthropic 계정으로 직접 전송됩니다(6항).

1. 수집하는 정보

없습니다. 회원가입·로그인·분석 도구·광고가 없습니다.

2. 디자인 파일

사용자가 직접 저장·열기·내보내기한 파일(.partsmith·STL·3MF)만 사용자의 PC에서 읽고 씁니다. 앱은 파일을 외부로 전송하지 않습니다.

3. 네트워크 사용

유료 기능(Partsmith Pro 애드온) 보유 여부를 확인하고 구매하기 위해 Microsoft Store 서비스와 통신합니다. 결제·계정 정보는 Microsoft가 처리하며 개발자는 받지 않습니다. Microsoft 개인정보처리방침 사용자가 앱 안 AI 채팅을 쓰는 경우에만 Anthropic API(api.anthropic.com)와 통신합니다(6항).

4. 로컬 저장

작업 중인 디자인의 자동 저장본과 앱 설정(창 위치, 로컬 AI 연결 포트·접근 토큰)을 앱 데이터 폴더에 저장합니다. AI 클라이언트가 앱을 찾을 수 있도록 연결 정보(포트·접근 토큰)와 연결용 프로그램을 %USERPROFILE%\.partsmith에 둡니다. 앱 안 AI 채팅용 Anthropic API 키를 입력한 경우, 키는 Windows 데이터 보호(DPAPI)로 암호화되어 이 PC의 앱 설정에만 저장되며 개발자에게 전송되지 않습니다. 같은 폴더에 무료 내보내기 사용 횟수를 기록합니다. Claude Desktop 확장 파일(Partsmith.mcpb)을 만들면 %USERPROFILE%\.partsmith에 저장합니다.

5. 로컬 AI 연결(MCP)

앱이 실행되는 동안 같은 PC 안에서만 접근할 수 있는 로컬 서버(127.0.0.1)를 열어, 사용자가 직접 등록한 AI 클라이언트(Claude Desktop·Claude Code·Codex 등)가 모델링 도구를 호출할 수 있게 합니다. 이 서버는 외부 네트워크에서 접근할 수 없고, 접근 토큰이 없는 요청과 웹페이지에서 온 요청을 거부합니다. 요청에 따라 열린 디자인의 내용(피처·치수·화면 이미지)을 그 AI 클라이언트에 전달합니다. 외부 AI 클라이언트의 계정은 앱이 받지 않습니다. AI 클라이언트가 받은 내용을 AI 제공자에게 보내는지는 사용자와 그 제공자 사이의 약관을 따르며, 앱 개발자는 그 내용을 받지 않습니다. 접근 토큰은 앱의 'AI 연결' 화면에서 언제든 새로 만들 수 있습니다.

6. 앱 안 AI 채팅(선택)

사용자가 자신의 Anthropic API 키를 입력하고 채팅을 보낼 때에만, 앱은 그 키로 Anthropic API에 직접 요청합니다. 이때 사용자가 입력한 메시지, 열린 디자인의 내용(피처·치수), 모델의 화면 이미지가 Anthropic으로 전송됩니다. 이 데이터의 처리와 사용료 청구는 사용자와 Anthropic 사이의 약관과 Anthropic 개인정보처리방침을 따르며, 개발자는 이 내용이나 키를 받지 않습니다. 키는 채팅 설정에서 언제든 삭제할 수 있고, 채팅을 쓰지 않으면 이런 전송은 일어나지 않습니다.
