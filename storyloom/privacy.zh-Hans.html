隐私政策 — StoryLoom

生效日期：2026年6月27日 · 最后更新：2026年6月27日

摘要： StoryLoom 不收集任何个人信息。项目、角色、关系图、时间线、备注、设置等所有数据均通过 SwiftData 仅保存在您的设备上，绝不会离开设备。开发者没有自有服务器，也完全没有分析、追踪或广告 SDK。数据唯一离开设备的情形，是您主动执行导出/分享时。

1. 我们收集的信息

开发者不收集任何个人信息。没有注册、登录或账户创建，也不会索取或存储姓名、电子邮件、电话号码等任何识别信息。您在应用中创建的所有内容均通过 SwiftData 仅保存在您的设备上，绝不会发送到任何开发者服务器。

  • 项目 / 世界观设定 — 您撰写的作品资料。仅保存在设备上。
  • 角色 / 关系图 — 您创建的人物以及人物之间的关系节点图。仅保存在设备上。
  • 时间线 / 分支 — 您构建的事件与分支时间线。仅保存在设备上。
  • 备注、设置、语言、主题 — 您的创作内容与应用使用环境值。同样仅保存在设备上。

2. 导出与分享

仅当您主动点按导出/分享时，StoryLoom 才会将您的数据生成为文件（Markdown / JSON / .storyloom）并交给 iOS 分享面板。

  • 导出文件的去向完全由您选择（保存到"文件"App、通过邮件或信息发送、分享到其他应用等）。
  • StoryLoom 不会将此数据发送到任何开发者服务器，也不会自动传输到任何外部目的地。
  • 您在分享面板中选择的目的地（例如第三方云或即时通讯应用）对数据的处理，遵循该服务自身的隐私政策。

3. 数据传输与第三方

开发者不会向外部传输任何数据，也不会与第三方共享。 不会就您的数据发起任何开发者端的网络请求。

  • 没有自有的后端服务器
  • 没有分析（Analytics）SDK
  • 没有崩溃报告 SDK
  • 不使用广告或追踪标识符（IDFA）；不弹出 ATT 授权请求

应用内购买由 Apple StoreKit / App Store 处理，由 Apple 依据其隐私政策处理，开发者不会收到相关数据。

4. 数据保留与删除

  • 所有数据仅存在于您的设备上，因此您拥有完全的控制权。
  • 您可以在应用内直接编辑或删除项目、角色、时间线等任意记录。
  • 删除应用会一并移除设备上保存的所有数据。应用内购买权益可通过您的 Apple 账户恢复。

5. 付款（应用内购买）

StoryLoom 免费提供，并可选购一次性的永久版 Pro。所有付款均由 Apple 的 App Store / StoreKit 处理，开发者不会看到或存储卡号等付款信息。付款与退款相关的数据处理遵循 Apple 的隐私政策。

6. 儿童隐私

StoryLoom 设计为适合所有年龄（4 岁以上）安全使用。我们不向包括儿童在内的任何人收集个人信息。

7. 本政策的变更

如本政策发生变更，我们将在本页面公布变更内容及生效日期。
