隐私政策 — Layerforge

生效日期：2026年10月4日 · 最后更新：2026年10月4日

摘要：Layerforge 是一款适用于 Windows 的基于图层的图像编辑应用，不运营任何自有服务器。您打开的图像和项目、AI 处理以及应用设置均仅在您的电脑上处理和保存。应用不含任何分析、广告或跟踪工具，也不会向 blue-code 发送任何用户数据。

1. 处理的信息

  • 图像和项目文件 — 您打开或导入的文件（JPEG、PNG、TIFF、HEIC、SVG、PSD/PSB、相机 RAW、Layerforge 项目 .comp）仅为编辑目的在您的电脑上读取和写入，不会上传。
  • 应用设置 — 面板大小、工具选项、最近使用的文件列表等偏好设置保存在本设备的应用设置文件中。
  • Pro 状态提示值 — 为了在启动时快速显示正确状态，最后一次确认的 Layerforge Pro 状态（是/否）保存在同一设置文件中。

2. AI 功能（对象选择、选择主体、移除背景）

AI 功能使用应用内置的模型（U²-Net、EfficientSAM）直接在您的电脑上运行。您的图像不会发送到任何服务器，应用也不会下载模型或收集处理结果。

3. 应用内购买（Layerforge Pro）

Layerforge Pro 是通过 Microsoft Store 销售的加载项。付款和订单处理由 Microsoft 负责，购买过程中处理的信息适用 Microsoft 隐私声明。Layerforge 仅通过 Windows 内置的 Microsoft Store 功能确认您的 Layerforge Pro 许可证是否有效以及 Store 中显示的价格，不会接收或保存您的姓名、电子邮件地址、付款信息等账户信息。

4. 与第三方共享

Layerforge 不会向任何第三方提供或共享用户数据。

  • 无分析工具
  • 无崩溃报告 SDK
  • 不使用广告或跟踪标识符
  • 不运营自有服务器

5. 使用的设备功能

  • 文件访问 — 仅读取和写入您通过文件对话框、拖放或“打开方式”选择的文件和文件夹。
  • 文件夹变更检测 — 打开 .comp 项目期间，仅监视该文件夹，以便在屏幕上反映其他程序所做的更改。
  • 剪贴板 — 仅在执行复制或粘贴时读取或写入图像。
  • 图形设备 — 使用 GPU 进行显示和 AI 处理。

6. 数据保留与删除

应用设置仅保存在本设备上，卸载 Layerforge 时会一并删除。您创建的图像和项目文件保留在您保存的位置，由您自行管理。

7. 账户与登录

Layerforge 无需注册或登录。

8. 儿童隐私

Layerforge 并非面向 13 岁以下儿童，也不会有意收集儿童的信息。

9. 本政策的变更

如本政策发生变更，我们将在本页面公布变更内容及生效日期。
