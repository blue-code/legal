개인정보처리방침 — Layerforge

시행일: 2026년 10월 4일 · 최종 업데이트: 2026년 10월 8일

요약: Layerforge는 Windows용 레이어 기반 이미지 편집 앱이며, 별도의 서버를 운영하지 않습니다. 사용자가 여는 이미지와 프로젝트, AI 기능 처리, 앱 설정은 모두 사용자 PC 안에서만 처리·저장됩니다. 분석·광고·트래킹 도구가 없으며, blue-code에 어떠한 사용자 데이터도 전송되지 않습니다. 선택 기능인 AI 에이전트 연결을 켜면, 사용자가 이 PC에서 실행한 AI 에이전트가 열린 문서를 읽을 수 있습니다(3항 참고).

1. 처리하는 정보

  • 이미지와 프로젝트 파일 — 사용자가 직접 열거나 가져온 파일(JPEG, PNG, TIFF, HEIC, SVG, PSD/PSB, 카메라 RAW, Layerforge 프로젝트 .comp)은 편집을 위해 PC 안에서만 읽고 씁니다. Layerforge가 외부로 전송하지 않습니다(선택 기능인 AI 에이전트 연결은 3항 참고).
  • 앱 설정 — 패널 크기, 도구 옵션, 최근 연 파일 목록 등 환경설정을 이 기기의 앱 설정 파일에 저장합니다.
  • Pro 사용 여부 표시값 — 시작 화면을 빠르게 표시하기 위해 마지막으로 확인한 Layerforge Pro 사용 여부(예/아니요)를 같은 설정 파일에 저장합니다.
  • AI 에이전트 연결 설정 — AI 에이전트 연결 허용 여부와 첫 실행 안내를 표시했는지 여부를 같은 설정 파일에 저장합니다.

2. AI 기능 (객체 선택·피사체 선택·배경 제거)

AI 기능은 앱에 포함된 모델(U²-Net, EfficientSAM)로 사용자 PC에서 직접 실행됩니다. 이미지가 외부 서버로 전송되지 않으며, 모델을 내려받거나 처리 결과를 수집하지도 않습니다.

3. 로컬 AI 에이전트 연결 (선택 기능)

사용자가 앱에서 직접 켠 경우(도움말 ▸ AI 에이전트 연결)에만, 이 PC에서 실행 중인 AI 에이전트(예: Claude Code, Codex)가 Layerforge를 도구로 사용할 수 있습니다. 연결은 현재 Windows 계정만 사용할 수 있는 기기 내부 통로로 이루어지며 네트워크 포트를 열지 않습니다. 기본값은 꺼짐이며 같은 곳에서 언제든 끌 수 있습니다. Layerforge는 AI 서비스 계정이나 API 키를 받거나 저장하지 않습니다.

연결된 에이전트는 사용자가 요청한 작업을 위해 열린 문서의 정보(레이어 이름, 크기, 설정 값 등)와 미리보기 이미지를 받을 수 있으며, 에이전트가 이를 자신의 AI 서비스로 전송할 수 있습니다. 이 전송은 Layerforge가 아니라 에이전트가 하며, 해당 에이전트 제공자의 개인정보처리방침이 적용됩니다. blue-code는 이 정보를 받지 않습니다.

4. 앱 내 구매 (Layerforge Pro)

Layerforge Pro는 Microsoft Store를 통해 판매되는 앱 내 추가 기능입니다. 결제와 주문 처리는 Microsoft가 수행하며, 이 과정에서 처리되는 정보에는 Microsoft 개인정보처리방침이 적용됩니다. Layerforge는 Windows가 제공하는 Microsoft Store 기능을 통해 Layerforge Pro 라이선스가 활성 상태인지 여부와 Store에 표시된 가격만 확인하며, 이름·이메일·결제 정보 등 계정 정보는 받거나 저장하지 않습니다.

5. 제3자 제공 및 공유

Layerforge는 어떠한 사용자 데이터도 제3자에게 제공하거나 공유하지 않습니다.

사용자가 직접 연결한 AI 에이전트(3항)는 사용자의 도구이며, 에이전트가 제공자에게 보내는 내용은 사용자와 그 제공자 사이의 약관을 따릅니다.

  • 분석(Analytics) 도구 없음
  • 크래시 리포팅 SDK 없음
  • 광고 또는 트래킹 식별자 미사용
  • 자체 서버 운영 안 함

6. 사용하는 기기 기능

  • 파일 접근 — 사용자가 파일 대화상자, 끌어 놓기, "연결 프로그램"으로 고른 파일과 폴더만 읽고 씁니다.
  • 폴더 변경 감지 — 열어 둔 .comp 프로젝트 폴더가 다른 프로그램에 의해 바뀌면 화면에 반영하기 위해 그 폴더만 감시합니다.
  • 클립보드 — 복사·붙여넣기 명령을 실행할 때만 이미지를 읽고 씁니다.
  • 그래픽 장치 — 화면 표시와 AI 처리를 위해 GPU를 사용합니다.
  • 로컬 연결 통로 — AI 에이전트 연결을 켠 동안에만 현재 Windows 계정만 쓸 수 있는 named pipe를 엽니다. 네트워크 포트는 열지 않습니다.

7. 데이터 보관 및 삭제

앱 설정은 이 기기에만 저장되며, Layerforge를 제거하면 함께 삭제됩니다. 사용자가 만든 이미지와 프로젝트 파일은 사용자가 저장한 위치에 그대로 남으며, 사용자가 직접 관리합니다.

8. 계정 및 로그인

Layerforge는 회원가입이나 로그인을 요구하지 않습니다.

9. 아동의 개인정보

Layerforge는 만 13세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 정보를 수집하지 않습니다.
