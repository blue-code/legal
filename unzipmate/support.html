자주 묻는 질문

Q. Finder 오른쪽 클릭에 메뉴가 안 나와요. 시스템 설정 → 개인정보 보호 및 보안 → 확장 프로그램 → "추가된 확장 프로그램" → Finder 확장에서 UnzipMate Finder를 켜주세요. 켠 뒤 Finder를 다시 시작하면 적용됩니다.
Q. 한글 zip을 풀었는데 파일 이름이 깨져 보여요. 설정 → 압축 해제 → "한글/일어/중문 zip 자동 인코딩 감지"가 켜져 있는지 확인하세요. 그래도 안 되면 메일로 zip 파일 하나만 보내주시면 분석해 드립니다.
Q. 7Z, RAR도 풀 수 있나요? 현재 버전은 ZIP / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ / GZ / BZ2 / XZ까지 지원합니다. 7Z와 RAR 지원은 다음 업데이트에서 추가될 예정입니다.
Q. 비밀번호가 걸린 zip은 어떻게 푸나요? 현재는 비밀번호 보호된 압축은 지원되지 않습니다. 비밀번호 입력 UI는 다음 업데이트 일정에 포함되어 있습니다.
Q. 압축 풀린 폴더가 어디 만들어지나요? 기본은 원본 zip 파일과 같은 위치에, 같은 이름의 폴더로 생성됩니다. 설정에서 "지정된 폴더"로 바꾸면 항상 한 폴더에 모을 수 있습니다.

FAQ

Q. The right-click menu doesn't show up in Finder. Open System Settings → Privacy & Security → Extensions → "Added Extensions" → Finder Extensions, and enable "UnzipMate Finder". Restart Finder afterwards.
Q. My Korean / Japanese ZIP still has garbled names. Make sure Settings → Extract → "Auto-detect Korean / Japanese / Chinese filenames" is ON. If it still misbehaves, email us a sample ZIP and we'll diagnose it.
Q. Does it support 7Z and RAR? This release supports ZIP / TAR / TAR.GZ / TAR.BZ2 / TAR.XZ / GZ / BZ2 / XZ. 7Z and RAR support is planned for the next update.
Q. How do I extract a password-protected ZIP? Password-protected archives aren't supported in this release. The password prompt is on the roadmap.
Q. Where does the extracted folder go? By default, into the same location as the original archive, in a folder with the same name. You can switch the destination to a fixed folder in Settings.
