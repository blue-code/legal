어떤 파일을 열 수 있나요?

PES, DST, JEF, EXP, VP3 파일과, 이 파일들이 든 ZIP 묶음을 열 수 있습니다. 파일 하나는 100 MB까지입니다.

파일은 어떻게 여나요?

iPhone·iPad에서는 파일 앱에서 파일을 누르거나, 메일·메신저의 공유 메뉴에서 StitchScope를 고르세요. Mac에서는 Finder에서 더블클릭하거나, 앱 창에 끌어다 놓거나, ⌘O를 누르세요.

무료로 어디까지 쓸 수 있나요?

열기, 확대·이동, 디자인 정보와 점검, 실 색 목록, 회전·반전, 후프 확인, 실 번호 보기, ZIP 둘러보기, 파일 앱·Finder 미리보기는 모두 무료입니다. ‘변환·내보내기 잠금 해제’를 한 번 구매하면 형식 변환, ZIP 일괄 저장, PNG·SVG 이미지, 실 목록 공유, 실물 크기 인쇄 템플릿을 쓸 수 있습니다. 구독이 아닙니다.

다른 기기에서도 쓸 수 있나요? 구매를 복원하려면요?

같은 Apple 계정이면 iPhone·iPad·Mac 모두에서 한 번 구매로 씁니다. 새 기기나 재설치 후에는 설정 → 구매 복원을 누르세요.

변환한 파일을 내 재봉틀이 읽을까요?

StitchScope는 바꾼 파일을 다시 읽어 모든 땀이 원본과 0.1 mm 이내인지 확인한 뒤에만 저장합니다. 다만 형식마다 담을 수 있는 정보가 달라(예: DST에는 실 색이 없습니다) 변환 화면에 바뀌는 점을 미리 보여 줍니다. 기종마다 호환성이 다를 수 있으니 본 작업 전에 꼭 시험 수를 놓아 보세요.

변환했는데 저장되지 않아요.

검증을 통과하지 못하면 잘못된 파일을 만들지 않으려고 저장하지 않습니다. 원본 형식과 바꾸려던 형식을 적어 아래 주소로 보내 주시면 확인하겠습니다.

후프 크기를 바꾸려면요?

설정 → 내 후프에서 자주 쓰는 후프를 고르거나 크기를 직접 입력하세요. 맞는지 판단은 실제 바늘이 떨어지는 지점을 기준으로 합니다.

실 번호가 실제 실과 조금 달라요.

실 번호는 파일에 저장된 색과 가장 가까운 색을 찾은 것입니다. 화면 색은 근사치이므로 실제 실과 비교해 고르세요.

파일 앱·Finder에 썸네일이 안 보여요.

StitchScope를 한 번 실행하면 미리보기 기능이 켜집니다. Mac Finder에서는 EXP 파일 썸네일이 표시되지 않을 수 있습니다(시스템이 이 확장자를 다른 형식으로 취급합니다). 앱에서는 정상적으로 열립니다.

파일이 어딘가로 전송되나요?

아니요. StitchScope는 인터넷 연결을 쓰지 않습니다. 모든 처리는 기기 안에서 하며, 원본 파일은 바꾸지 않고 변환 결과는 항상 새 파일로 저장합니다.

Windows판과 구매가 연동되나요?

아니요. Windows판은 Microsoft Store에서 따로 제공하며, App Store 구매와는 별개입니다.

Which files can I open?

PES, DST, JEF, EXP and VP3 files, and ZIP packs that contain them. Each file can be up to 100 MB.

How do I open a file?

On iPhone and iPad, tap the file in the Files app, or choose StitchScope from the share menu in Mail or a messaging app. On Mac, double-click it in Finder, drag it onto the app window, or press ⌘O.

What is free?

Opening, zoom and pan, design info and checks, the color list, rotate and flip, hoop fit, thread numbers, browsing ZIP packs, and Files/Finder previews are all free. A one-time purchase of “Unlock Conversion & Export” adds format conversion, saving whole ZIP packs, PNG and SVG images, sharing the thread list, and the actual-size print template. It is not a subscription.

Can I use it on my other devices? How do I restore my purchase?

With the same Apple Account, one purchase works on iPhone, iPad and Mac. On a new device or after reinstalling, go to Settings → Restore Purchases.

Will my machine read the converted file?

StitchScope reads the converted file back and saves it only if every stitch stays within 0.1 mm of the original. Formats store different things — DST has no thread colors, for example — so the Convert screen lists what will change. Machines vary, so always sew a test before the real piece.

I converted a design, but nothing was saved.

If the check fails, StitchScope does not save, so you never get a broken file. Email us the original format and the format you chose, and we will look into it.

How do I change my hoop sizes?

Go to Settings → My Hoops and pick common hoops or enter your own size. Fit is measured from the actual needle points.

The thread numbers don’t quite match my threads.

Thread numbers are the closest match to the colors stored in the file. Screen colors are approximate, so compare with your real threads.

I don’t see thumbnails in Files or Finder.

Open StitchScope once to turn on previews. Mac Finder may not show thumbnails for EXP files, because macOS treats that extension as another file type. The app still opens them.

Are my files sent anywhere?

No. StitchScope does not use the internet. Everything is processed on your device; the original file is never changed and conversions are always saved as new files.

Does my purchase carry over to the Windows version?

No. The Windows version is sold separately on the Microsoft Store, apart from App Store purchases.

どのファイルを開けますか?

PES・DST・JEF・EXP・VP3ファイルと、それらを含むZIPを開けます。1ファイル100 MBまでです。

ファイルはどう開きますか?

iPhone・iPadではファイルAppでファイルをタップするか、メールやメッセージの共有メニューからStitchScopeを選びます。MacではFinderでダブルクリック、アプリのウインドウへドラッグ、または⌘Oを押します。

無料でどこまで使えますか?

開く、拡大・移動、デザイン情報とチェック、色リスト、回転・反転、刺繍枠の確認、糸番号の表示、ZIPの閲覧、ファイルApp・Finderのプレビューはすべて無料です。「変換・書き出しのロック解除」を一度購入すると、形式の変換、ZIPの一括保存、PNG・SVG画像、糸リストの共有、実物大の印刷テンプレートが使えます。サブスクリプションではありません。

ほかのデバイスでも使えますか? 購入を復元するには?

同じApple Accountなら、iPhone・iPad・Macのすべてで一度の購入で使えます。新しいデバイスや再インストール後は、設定 → 購入を復元 を押してください。

変換したファイルはミシンで読めますか?

StitchScopeは変換したファイルを読み直し、すべての針目が元から0.1 mm以内のときだけ保存します。ただし形式ごとに保存できる情報が異なるため(例: DSTには糸の色がありません)、変換画面で変わる点を事前に表示します。機種により互換性が異なる場合があるので、本番の前に必ず試し縫いをしてください。

変換したのに保存されません。

検証に通らない場合は、壊れたファイルを作らないよう保存しません。元の形式と変換先の形式を下記アドレスまでお知らせください。

刺繍枠のサイズを変えるには?

設定 → マイ刺繍枠 で一般的な刺繍枠を選ぶか、サイズを直接入力してください。収まるかどうかは実際の針落ち位置で判定します。

糸番号が実際の糸と少し違います。

糸番号はファイルに保存された色に最も近いものを探した結果です。画面の色は目安なので、実際の糸と見比べて選んでください。

ファイルAppやFinderにサムネイルが出ません。

StitchScopeを一度起動するとプレビューが有効になります。MacのFinderではEXPファイルのサムネイルが表示されないことがあります(システムがこの拡張子を別の形式として扱うため)。アプリでは通常どおり開けます。

ファイルはどこかに送信されますか?

いいえ。StitchScopeはインターネット接続を使いません。すべての処理はデバイス内で行い、元のファイルは変更せず、変換結果は常に新しいファイルとして保存します。

Windows版と購入は共有されますか?

いいえ。Windows版はMicrosoft Storeで別途提供しており、App Storeでの購入とは別です。

可以打开哪些文件？

PES、DST、JEF、EXP、VP3 文件，以及包含这些文件的 ZIP 压缩包。单个文件最大 100 MB。

如何打开文件？

在 iPhone、iPad 上，在“文件”App 中轻点文件，或在邮件、聊天应用的共享菜单中选择 StitchScope。在 Mac 上，在 Finder 中双击、拖到应用窗口，或按 ⌘O。

免费可以用到什么程度？

打开、缩放与移动、设计信息与检查、颜色列表、旋转与翻转、绣框检查、查看线号、浏览 ZIP、“文件”与 Finder 预览均免费。一次购买“解锁转换与导出”后，可使用格式转换、ZIP 批量保存、PNG/SVG 图片、分享绣线清单以及实际尺寸打印模板。这不是订阅。

其他设备也能用吗？如何恢复购买？

使用同一个 Apple 账户，一次购买即可在 iPhone、iPad、Mac 上使用。在新设备或重新安装后，请前往 设置 → 恢复购买。

转换后的文件我的绣花机能读吗？

StitchScope 会回读转换后的文件，只有每一针与原文件相差都在 0.1 mm 以内时才保存。不过各格式能保存的信息不同(例如 DST 没有绣线颜色)，转换界面会事先列出变化。不同机型兼容性可能不同，正式刺绣前请务必先试绣。

转换了却没有保存。

如果没有通过验证，为避免生成损坏的文件，就不会保存。请将原格式和目标格式发送到下方邮箱，我们会尽快查看。

如何更改绣框尺寸？

前往 设置 → 我的绣框，选择常用绣框或直接输入尺寸。是否合适以实际落针点为准。

线号与实际绣线略有不同。

线号是与文件中保存的颜色最接近的结果。屏幕颜色仅供参考，请对照实际绣线挑选。

“文件”或 Finder 中看不到缩略图。

启动一次 StitchScope 后预览功能才会启用。Mac 的 Finder 可能不显示 EXP 文件的缩略图(系统把该扩展名视为其他类型)，但在应用中可以正常打开。

文件会被发送到别处吗？

不会。StitchScope 不使用互联网。所有处理都在设备上完成，原文件不会被修改，转换结果始终另存为新文件。

购买可以和 Windows 版共用吗？

不可以。Windows 版另行在 Microsoft Store 提供，与 App Store 购买相互独立。
