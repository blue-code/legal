개인정보처리방침 — StitchScope

시행일: 2026-10-05 · 게시자: 수카버스

StitchScope는 자수 파일을 이 PC에서만 열고 변환하는 Windows 앱이다. 계정을 만들지 않으며, 앱이 네트워크로 내용을 보내지 않는다.

수집하는 정보

앱은 개인정보를 수집하지 않는다.

  • 계정, 이메일, 이름, 결제 정보를 받지 않는다.
  • 자수 파일을 서버로 올리지 않는다.
  • 분석, 광고, 충돌 보고 SDK를 넣지 않는다.
  • 위치, 연락처, 카메라, 마이크를 쓰지 않는다.

이 PC에서 하는 일

사용자가 고른 자수 파일만 읽는다. 변환과 그림 저장은 사용자가 지정한 새 파일에만 쓴다. 같은 이름의 파일이 있으면 번호를 붙여 다른 이름으로 저장하고, 기존 파일은 바꾸지 않는다. 읽기 도중 경로는 임시 폴더의 복사본으로만 넘긴다. 임시 복사본은 읽기가 끝나면 지운다.

스토어

Microsoft Store가 앱 설치와 결제에 대해 따로 처리하는 정보는 Microsoft의 개인정보 처리방침을 따른다. StitchScope 앱 안에서는 그 정보를 받지 않는다. 이 버전에 앱 내부 결제는 없다. 가격이 있다면 Microsoft Store의 일회 구매 가격이다.

아동

앱은 아동을 대상으로 하지 않는다. 아동의 정보를 모으는 기능이 없고, 수집 자체가 없다.

문의

개인정보 문의는 스토어 제품 페이지의 게시자 연락처로 한다.

변경

이 방침이 바뀌면 시행일을 고친다. 앱이 네트워크로 내용을 보내기 시작하면 그 전에 방침과 스토어 목록을 먼저 고친다.

Privacy Policy — StitchScope

Effective date: 2026-10-05 · Publisher: 수카버스

StitchScope is a Windows app that opens and converts embroidery files on this PC only. It does not create an account, and it does not send file contents over the network.

Information we collect

The app does not collect personal information.

  • It does not ask for an account, email, name, or payment details.
  • It does not upload embroidery files to a server.
  • It does not include analytics, advertising, or crash-reporting SDKs.
  • It does not use location, contacts, the camera, or the microphone.

What happens on this PC

The app reads only the embroidery file you choose. Conversion and picture export write only to a new file you name. If that name is already used, StitchScope saves a numbered copy and leaves the existing file unchanged. While reading, the path is handed to the reader as a copy in a temporary folder. That copy is deleted when the read finishes.

The Store

Information that Microsoft Store processes for installation and payment is covered by the Microsoft Privacy Statement. StitchScope does not receive that information inside the app. This version has no in-app purchase. If the app has a price, it is a one-time Microsoft Store purchase.

Children

The app is not directed at children. It has no feature that collects information about children, and it does not collect personal information at all.

Contact

Privacy questions go to the publisher contact shown on the Store product page.

Changes

If this policy changes, the effective date is updated. If the app starts sending contents over the network, the policy and the Store listing are updated first.
