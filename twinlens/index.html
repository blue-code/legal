TwinLens

두 시선, 하나의 추억 · Two views, one memory

TwinLens는 두 사람의 시선으로 완성되는, 서버 없는 온디바이스 커플 추억 다이어리입니다. 같은 순간을 각자의 시선으로 찍으면, 온디바이스 AI가 하나의 추억으로 엮어줍니다.

서버 없음계정 없음광고추적 없음온디바이스 AI
