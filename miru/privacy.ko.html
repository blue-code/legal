미루(Miru) — 개인정보 처리방침

시행일: 2026-07-19 · 최종 수정: 2026-07-19

미루는 온디바이스 AI 친구 앱입니다. 핵심을 먼저 말씀드리면, 기본 설정에서 미루에게 하는 말은 당신의 기기를 절대 벗어나지 않으며, 저희는 어떤 데이터도 수집·저장·전송하지 않습니다.

수집하는 정보

없습니다. 미루는 계정, 분석 도구, 저희가 운영하는 서버가 없습니다. 대화 내용, 친구(캐릭터) 설정, 미루가 기억하는 메모는 모두 당신의 기기 안에만 저장됩니다(당신이 직접 관리하는 iCloud·기기 백업 제외).

온디바이스 두뇌 (기본)

기본적으로 미루는 애플의 온디바이스 Foundation Models로 답변을 생성하며, 이는 아이폰 안에서 로컬로 실행됩니다. 대화는 기기에서 처리되고 저희나 제3자에게 전송되지 않습니다.

내 API 키 사용 (선택)

미루에는 본인의 제3자 AI 제공자(OpenAI, Anthropic 등) API 키를 입력해 사용하는 선택 기능이 있습니다. 이 기능을 켠 경우에 한해, 당신의 메시지는 기기에서 당신이 선택한 제공자에게 직접 전송되며, 해당 제공자의 개인정보 방침과 당신의 계정 하에서 처리됩니다. 미루는 이 메시지나 키를 어떤 서버에서도 수신·중계·기록·저장하지 않습니다. API 키는 기기의 키체인에만 저장되고 당신이 선택한 제공자에게만 전송되며, 설정에서 언제든 삭제할 수 있습니다.

음성

미루의 음성(TTS)은 애플의 온디바이스 음성 합성을 사용합니다. 어떤 오디오도 저희에게 전송되지 않습니다.

구매

선택 사항인 평생 이용권 "미루 Pro"는 애플 App Store / StoreKit에서 처리됩니다. 저희는 결제 정보를 볼 수 없으며, 이용 권한은 기기에서 확인됩니다.

어린이

미루는 자유로운 AI 대화가 성숙한 주제를 다룰 수 있어 만 17세 이상 이용자를 위한 앱입니다. 어린이를 대상으로 하지 않습니다.

AI에 대한 안내

미루는 AI 친구입니다. 부정확할 수 있으며 전문적인 조언·상담·위기 지원을 대신하지 않습니다. 힘든 상황이라면 전문가나 지역 위기 상담 전화에 도움을 요청해 주세요.
