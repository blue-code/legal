개인정보처리방침 — PackNine

시행일: 2026년 9월 30일 · 최종 업데이트: 2026년 9월 30일

요약: PackNine은 별도의 백엔드 서버를 운영하지 않는 Windows 데스크톱 압축 프로그램입니다. 압축하거나 해제한 파일은 모두 사용자 PC 내부에서만 처리됩니다. 분석/광고/트래킹 SDK가 전혀 없으며, blue-code 서버로 어떠한 사용자 데이터도 전송되지 않습니다.

1. 수집하지 않는 정보

PackNine은 다음을 일절 수집·전송·저장하지 않습니다.

  • 이름, 이메일 주소, 계정 정보 등 개인을 식별할 수 있는 정보
  • 압축하거나 해제한 파일의 이름, 내용, 경로
  • 사용 통계, 분석 데이터, 텔레메트리, 크래시 리포트
  • IP 주소, 기기 식별자, 위치 정보
  • 광고 식별자 (PackNine에는 광고가 없습니다)

2. 제3자 제공 및 공유

PackNine은 어떠한 사용자 데이터도 제3자에게 제공하거나 공유하지 않습니다.

  • 분석(Analytics) 도구 없음
  • 크래시 리포팅 SDK 없음
  • 광고 또는 트래킹 식별자 미사용
  • 자체 백엔드 서버 운영 안 함

3. 네트워크 통신

PackNine은 정상 동작 과정에서 인터넷에 접속하지 않습니다. 외부 서버와 통신하는 기능이 없으며, 자동 업데이트 확인도 수행하지 않습니다. Microsoft Store 배포판은 Store 자체 업데이트 메커니즘을 사용합니다.

4. 로컬에 저장되는 정보

진단 목적으로 실행 기록을 사용자 컴퓨터에만 남깁니다.

  • 위치 — %LOCALAPPDATA%\PackNine\packnine-debug.log
  • 내용 — 실행 시각, 전달받은 명령줄 인자, 오류 발생 시 스택 트레이스
  • 용도 — 탐색기 우클릭 메뉴처럼 콘솔이 없는 환경에서 오류 원인을 추적하기 위함
  • 전송 — 어디에도 전송되지 않습니다. 사용자가 직접 열어 보거나 삭제할 수 있습니다.

일반 설치본(GitHub 배포)은 파일 연결과 우클릭 메뉴 등록을 위해 현재 사용자 레지스트리(HKEY_CURRENT_USER)에만 설정값을 기록하며, 프로그램 제거 시 원래 상태로 복원합니다. Microsoft Store 배포판은 파일 연결을 Windows가 패키지 정보로 관리하므로 레지스트리를 직접 수정하지 않습니다.

5. 권한 안내

PackNine은 다음 로컬 기능을 사용하며, 모두 사용자 기기 내에서만 동작합니다.

  • 파일 시스템 접근 — 사용자가 직접 선택한 파일과 폴더를 압축·해제·미리보기하기 위해 읽고 씁니다. 사용자가 선택하지 않은 파일을 탐색하거나 열지 않습니다.
  • 로컬 프로세스 실행 — RAR 형식 해제 시 시스템에 설치된 unrar 또는 bsdtar 실행 파일에 위임합니다.
  • 전체 신뢰(runFullTrust) — 일반 데스크톱 앱으로 동작하기 위해 Microsoft Store 패키지가 선언하는 권한입니다. 이 권한으로 추가 정보를 수집하지 않습니다.

6. 데이터 보관 및 삭제

%LOCALAPPDATA%\PackNine 폴더를 삭제하면 로그를 포함한 모든 로컬 데이터가 제거됩니다.

7. 계정 및 로그인

PackNine은 회원가입이나 로그인을 요구하지 않습니다.

8. 아동의 개인정보

PackNine은 만 13세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 정보를 수집하지 않습니다.
