Compendium Lab 개인정보처리방침

최종 수정: 2026년 7월 17일

Compendium Lab은 계정, 분석 도구, 광고 SDK 또는 추적 기술을 사용하지 않으며 개발자가 개인정보를 수집하지 않습니다.

기기 및 iCloud 데이터

읽기 진도, 북마크, 코드 초안은 기기에 저장됩니다. 사용자가 iCloud를 활성화한 경우 Apple의 비공개 CloudKit 데이터베이스를 통해 사용자의 기기 사이에서 동기화됩니다. 개발자는 이 비공개 데이터에 접근하지 않습니다.

콘텐츠와 외부 링크

앱은 번들된 강의와 Python 런타임을 오프라인으로 사용합니다. 사용자가 외부 링크를 직접 선택하면 시스템 브라우저가 해당 사이트를 엽니다.
