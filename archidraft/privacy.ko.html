ArchiDraft 개인정보처리방침

ArchiDraft는 개인정보를 수집·저장·전송하지 않습니다.

1. 수집하는 정보

없습니다. 회원가입·로그인·분석 도구·광고가 없습니다.

2. 도면 파일

사용자가 직접 열거나 저장한 파일(DWG·DXF·PDF)만 사용자의 PC에서 읽고 씁니다. 파일은 외부로 전송되지 않습니다.

3. 네트워크 사용

유료 기능(애드온) 보유 여부를 확인하고 구매하기 위해 Microsoft Store 서비스와 통신합니다. 결제·계정 정보는 Microsoft가 처리하며 개발자는 받지 않습니다. Microsoft 개인정보처리방침

4. 로컬 저장

마지막으로 확인한 라이선스 등급을 %LOCALAPPDATA%\ArchiDraft\license.json에 저장합니다(오프라인 사용용). 개인정보는 들어 있지 않습니다.
