이용약관 — MemoGraph

최종 업데이트: 2026년 5월 30일

본 약관은 사용자가 MemoGraph(이하 "앱")를 이용함에 있어 적용되는 조건을 규정합니다. 앱을 설치하거나 사용함으로써 사용자는 본 약관에 동의하는 것으로 간주됩니다.

1. 서비스 개요

MemoGraph는 로컬-퍼스트(local-first) 방식의 개인용 지식 그래프 노트 앱입니다. 사용자가 입력한 메모는 기기 또는 사용자 본인의 iCloud 계정에 Markdown(.md) 파일로 저장되며, 엔티티·관계 추출, 음성 입력, (선택적) AI 자동 분류, (선택적) iCloud 동기화 기능을 제공합니다.

2. AI 기능 및 사용자 API 키

AI 자동 분류 기능은 사용자가 설정에서 직접 입력한 Google Gemini API 키로 동작합니다.

  • 사용자는 본인 명의의 Google API 키 사용에 따른 Google 약관, 요금, 사용량 한도(quota)에 대한 책임을 집니다.
  • 이 기능을 사용할 때, 분류 대상 입력 텍스트가 Google Gemini API로 전송되어 처리됩니다. 전송된 텍스트의 처리는 Google의 정책을 따릅니다.
  • API 키를 입력하지 않으면 텍스트가 외부로 전송되지 않으며, 노트 작성·지식 그래프 보기·탐색·저장 등 핵심 기능은 정상 동작합니다.

3. 사용자 콘텐츠 및 소유권

사용자가 앱에서 작성한 모든 메모와 지식 그래프 데이터의 소유권은 전적으로 사용자에게 있습니다. 데이터는 사용자의 기기 또는 사용자 본인의 iCloud 계정에만 저장되며, 운영자는 이에 접근할 수 없습니다. 데이터의 백업 및 보관은 사용자의 책임입니다.

4. 보증의 부인

앱은 "있는 그대로(as is)" 제공됩니다. 운영자는 앱이 오류 없이 작동하거나 특정 목적에 적합함을 보증하지 않습니다. 특히 AI 자동 분류 결과의 정확성·완전성을 보증하지 않으므로, 중요한 정보는 사용자가 직접 검증해야 합니다.

5. 책임의 제한

운영자는 법이 허용하는 범위 내에서, 앱 사용 과정에서 발생하는 데이터 손실, 동기화 오류, 기기 오작동, 또는 제3자 서비스(Google Gemini 등)의 장애·과금으로 인한 손해에 대해 책임을 지지 않습니다.

6. 금지 행위

사용자는 앱을 불법적인 목적으로 사용하거나, 앱을 역설계(reverse engineering)·무단 복제·재배포해서는 안 됩니다.

7. 지식재산권

앱 자체 및 그 디자인, 상표에 대한 지식재산권은 운영자에게 있습니다. 사용자가 생성한 콘텐츠는 본 조항의 적용을 받지 않습니다.

8. 약관의 변경

본 약관은 변경될 수 있으며, 변경 시 본 페이지에 공지됩니다.
