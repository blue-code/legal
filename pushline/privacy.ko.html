개인정보처리방침 — PUSH LINE

시행일: 2026년 10월 2일 · 최종 업데이트: 2026년 10월 2일

요약: PUSH LINE은 인터넷 연결 없이 동작하는 Windows용 로컬 2인 보드게임입니다. 어떠한 개인정보도 수집하거나 전송하지 않습니다. 게임 설정만 사용자 PC에 저장됩니다.

1. 수집·저장하는 정보

PUSH LINE은 개인정보를 수집하지 않으며 네트워크 통신을 하지 않습니다. 다음 정보만 사용자 PC의 로컬 저장소에 보관됩니다.

  • 게임 설정 — 언어, 전체 화면, 진동, 효과음, 글자 크기, 매치 방식 등 (%LOCALAPPDATA%\PushLine\settings.json. Microsoft Store 설치본은 앱 전용 폴더에 저장)

대국 기록, 계정, 기기 식별자는 저장하지 않습니다.

2. 제3자 제공 및 공유

PUSH LINE은 어떠한 사용자 데이터도 제3자에게 제공하거나 공유하지 않습니다.

  • 분석(Analytics) 도구 없음
  • 크래시 리포팅 SDK 없음
  • 광고 및 트래킹 식별자 없음
  • 자체 서버 운영 안 함

3. 구매

게임 구매와 결제는 Microsoft Store가 처리하며, 결제 정보는 개발자에게 전달되지 않습니다. 이 과정에는 Microsoft 개인정보처리방침이 적용됩니다.

4. 권한 안내

  • 게임 컨트롤러·키보드 입력 — 게임 조작을 위해 PC에 연결된 컨트롤러 입력을 로컬에서만 읽습니다.
  • 전체 신뢰(runFullTrust) — 일반 Windows 실행 파일로 동작하기 위해 필요하며, 설정 파일 저장 외의 용도로 쓰지 않습니다.

5. 데이터 보관 및 삭제

앱을 제거하거나 위 설정 파일을 삭제하면 모든 로컬 데이터가 제거됩니다.

6. 아동의 개인정보

PUSH LINE은 전체이용가 게임이며, 아동을 포함한 누구의 개인정보도 수집하지 않습니다.

7. 처리방침의 변경

본 처리방침이 변경될 경우 본 페이지에 변경 사항과 시행일을 게시합니다.
