Privacy Policy — PUSH LINE

Effective: October 2, 2026 · Last updated: October 2, 2026

Summary: PUSH LINE is an offline, local two-player board game for Windows. It does not collect or transmit any personal information. Only your game settings are stored on your PC.

1. Information we store

PUSH LINE collects no personal information and makes no network connections. Only the following is stored locally on your PC:

  • Game settings — language, fullscreen, vibration, sound effects, text size, match format (%LOCALAPPDATA%\PushLine\settings.json; Microsoft Store installs keep it in the app's private folder)

No game history, accounts or device identifiers are stored.

2. Sharing with third parties

PUSH LINE does not provide or share any user data with third parties.

  • No analytics
  • No crash-reporting SDK
  • No advertising or tracking identifiers
  • No backend server

3. Purchases

Purchases and payments are handled by the Microsoft Store; payment details are never shared with the developer. The Microsoft Privacy Statement applies to that process.

4. Permissions

  • Game controller and keyboard input — read locally to control the game.
  • Full trust (runFullTrust) — required to run as a standard Windows executable; used only to save the settings file.

5. Retention and deletion

Uninstalling the app or deleting the settings file above removes all local data.

6. Children's privacy

PUSH LINE is rated for all ages and does not collect personal information from anyone, including children.

7. Changes to this policy

If this policy changes, the changes and their effective date will be posted on this page.
