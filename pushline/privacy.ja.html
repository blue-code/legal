プライバシーポリシー — PUSH LINE

施行日: 2026年10月2日 · 最終更新: 2026年10月2日

概要: PUSH LINE はインターネット接続なしで動作する Windows 向けローカル2人対戦ボードゲームです。個人情報を一切収集・送信しません。ゲーム設定のみがお使いの PC に保存されます。

1. 保存する情報

PUSH LINE は個人情報を収集せず、ネットワーク通信も行いません。お使いの PC には次の情報のみが保存されます。

  • ゲーム設定 — 言語、フルスクリーン、振動、効果音、文字サイズ、マッチ形式など（%LOCALAPPDATA%\PushLine\settings.json。Microsoft Store 版はアプリ専用フォルダーに保存）

対戦履歴、アカウント、デバイス識別子は保存しません。

2. 第三者への提供・共有

PUSH LINE はいかなるユーザーデータも第三者に提供・共有しません。

  • 分析ツールなし
  • クラッシュレポート SDK なし
  • 広告・トラッキング識別子なし
  • 独自サーバーの運用なし

3. 購入

購入と決済は Microsoft Store が処理し、決済情報が開発者に渡ることはありません。この過程には Microsoft のプライバシーに関する声明が適用されます。

4. 権限について

  • ゲームコントローラー・キーボード入力 — ゲーム操作のためにローカルでのみ読み取ります。
  • 完全信頼（runFullTrust） — 通常の Windows 実行ファイルとして動作するために必要で、設定ファイルの保存以外には使用しません。

5. 保存期間と削除

アプリをアンインストールするか上記の設定ファイルを削除すると、すべてのローカルデータが削除されます。

6. 子どものプライバシー

PUSH LINE は全年齢対象のゲームであり、子どもを含む誰の個人情報も収集しません。

7. 本ポリシーの変更

本ポリシーを変更する場合は、変更内容と施行日を本ページに掲載します。
