隐私政策 — PUSH LINE

生效日期：2026年10月2日 · 最后更新：2026年10月2日

摘要：PUSH LINE 是一款无需联网即可运行的 Windows 本地双人棋盘游戏。不收集、不传输任何个人信息。只有游戏设置保存在您的电脑上。

1. 存储的信息

PUSH LINE 不收集个人信息，也不进行任何网络通信。只有以下信息保存在您电脑的本地存储中：

  • 游戏设置 — 语言、全屏、振动、音效、文字大小、比赛形式等（%LOCALAPPDATA%\PushLine\settings.json；Microsoft Store 版本保存在应用专用文件夹中）

不保存对局记录、账户或设备标识符。

2. 向第三方提供与共享

PUSH LINE 不向任何第三方提供或共享用户数据。

  • 无分析工具
  • 无崩溃报告 SDK
  • 无广告或追踪标识符
  • 不运营自有服务器

3. 购买

购买与支付由 Microsoft Store 处理，支付信息不会提供给开发者。此过程适用 Microsoft 隐私声明。

4. 权限说明

  • 游戏手柄与键盘输入 — 仅在本地读取，用于操作游戏。
  • 完全信任（runFullTrust） — 作为普通 Windows 可执行文件运行所必需，仅用于保存设置文件。

5. 数据保留与删除

卸载应用或删除上述设置文件即可移除所有本地数据。

6. 儿童隐私

PUSH LINE 为全年龄游戏，不收集包括儿童在内的任何人的个人信息。

7. 政策变更

如本政策发生变更，我们将在本页面公布变更内容及生效日期。
