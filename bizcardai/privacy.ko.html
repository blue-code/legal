개인정보처리방침 — BizCard AI

시행일: 2026년 5월 18일 · 최종 업데이트: 2026년 5월 18일

요약: BizCard AI는 모든 처리를 기기 내에서만 수행합니다. 명함 이미지, OCR 텍스트, 추출된 연락처 정보는 절대 기기를 벗어나지 않습니다. 분석/추적/광고 SDK가 전혀 없으며, 어떠한 네트워크 요청도 발생시키지 않습니다.

1. 수집·저장하는 정보

BizCard AI는 외부 서버로 어떠한 정보도 전송하지 않습니다. 모든 데이터는 사용자 기기 내 앱 샌드박스 또는 사용자가 직접 허용한 iOS 시스템 영역(연락처)에만 저장됩니다.

  • 명함 이미지 — 카메라 또는 사진 라이브러리에서 가져온 이미지. 기기 내 처리 후 사용자가 저장을 선택하지 않으면 즉시 폐기됩니다.
  • OCR 텍스트 결과 — Apple의 온디바이스 Vision/VisionKit 프레임워크로 추출. 기기 외부로 전송되지 않습니다.
  • 파싱된 연락처 데이터(이름, 회사, 전화, 이메일 등) — 사용자가 명시적으로 저장/내보내기 한 경우에만 앱 내 또는 iOS 연락처에 저장됩니다.

2. 제3자 제공 및 공유

BizCard AI는 어떠한 데이터도 제3자에게 제공하거나 공유하지 않습니다.

  • 분석(Analytics) 도구 없음
  • 크래시 리포팅 SDK 없음
  • 광고 또는 트래킹 식별자(IDFA) 미사용
  • 자체 백엔드 서버 운영 안 함 — 네트워크 호출 자체가 발생하지 않습니다.

3. 권한 안내

앱은 다음 iOS 권한을 요청할 수 있으며, 각 권한의 사용 목적은 다음과 같습니다.

  • 카메라 — 명함을 촬영하기 위해 사용. 캡처된 이미지는 기기 내에서만 처리됩니다.
  • 사진 라이브러리 (선택) — 사용자가 이미 촬영해 둔 명함 이미지를 직접 선택하는 경우에만 사용. 라이브러리 전체를 스캔하지 않으며, 선택한 이미지만 읽습니다.
  • 연락처 — 사용자가 "연락처에 추가" 버튼을 누른 명함만 iOS 연락처에 저장합니다. 기존 연락처를 읽어가거나 외부로 전송하지 않습니다.

모든 권한은 iOS 설정 앱에서 언제든 취소할 수 있으며, 권한이 없어도 앱의 기본 사용에는 제한이 있을 뿐 데이터가 임의로 수집되지 않습니다.

4. 데이터 보관 및 삭제

  • 앱 내 저장된 명함 항목은 사용자가 직접 삭제할 수 있습니다.
  • 앱을 삭제하면 앱 샌드박스 내 모든 데이터(이미지, OCR 결과, 파싱된 연락처)가 즉시 제거됩니다.
  • iOS 연락처에 저장된 항목은 iOS 연락처 앱에서 직접 관리합니다.

5. 계정 및 로그인

BizCard AI는 계정 생성이나 로그인을 요구하지 않습니다. 이메일, 전화번호, SNS 인증 등 어떠한 식별자도 요구하지 않습니다.

6. 사용자의 권리

  • 모든 데이터는 사용자 기기 내에 존재하므로, 사용자가 완전한 통제권을 가집니다.
  • 접근/수정/삭제 권리는 앱 내 UI 및 iOS 시스템 설정을 통해 직접 행사할 수 있습니다.
  • GDPR, CCPA 등 관련 법령상의 권리에 대한 문의는 아래 연락처로 보내주십시오.

7. 아동의 개인정보

BizCard AI는 만 13세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 정보를 수집하지 않습니다.

8. 처리방침의 변경

본 처리방침이 변경될 경우 본 페이지에 변경 사항과 시행일을 게시합니다. 중대한 변경 시 앱 내 공지를 통해 안내합니다.
