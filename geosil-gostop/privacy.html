개인정보처리방침 — 거실고스톱

최종 업데이트: 2026년 5월 10일

본 앱(이하 "거실고스톱")은 사용자의 개인정보를 소중히 여기며, 본 처리방침에 따라 투명하고 안전하게 처리합니다. 거실고스톱은 오직 같은 와이파이/블루투스 범위 내의 다른 기기와 P2P로 연결하여 동작하며, 회사의 어떤 서버로도 사용자 정보를 전송하지 않습니다.

1. 수집하는 정보

거실고스톱은 다음 정보를 사용자 기기 내에서만 처리합니다.

항목처리 위치외부 전송
플레이어 닉네임 (사용자가 직접 입력)iOS UserDefaults같은 게임 방의 다른 플레이어에게만 P2P로 표시
게임 진행 상태 (손패, 점수)메모리같은 게임 방의 다른 플레이어와 P2P로만 동기화

2. 수집하지 않는 정보

  • 이메일, 전화번호, 주소 등 식별 정보 — 일절 수집하지 않습니다.
  • 위치 정보, 사진, 연락처 — 접근 권한 자체를 요청하지 않습니다.
  • 광고 식별자(IDFA), 추적 데이터 — 사용하지 않습니다.
  • 결제 정보 — 본 앱은 인앱 구매가 없습니다.

3. 정보의 외부 전송

본 앱은 어떠한 분석 도구, 광고 SDK, 클라우드 서버에도 사용자 데이터를 전송하지 않습니다. 모든 게임 진행은 같은 네트워크 내의 다른 플레이어와 직접 P2P로만 이루어집니다.

4. 로컬 네트워크 권한

iOS는 근처 기기 발견을 위해 "로컬 네트워크" 권한을 요청합니다. 이 권한은 같은 와이파이의 다른 거실고스톱 기기를 찾기 위해서만 사용되며, 다른 어떤 용도로도 사용되지 않습니다.

5. 보안

P2P 통신은 Apple의 Multipeer Connectivity 프레임워크의 기본 암호화(encryptionPreference: .required)를 사용합니다.

6. 아동 개인정보 보호

본 앱은 만 13세 미만 아동으로부터 개인정보를 수집하지 않습니다. 외부 통신과 채팅 기능이 없어 4+ 등급에 적합합니다.

7. 변경

본 처리방침은 기능 변경에 따라 수정될 수 있으며, 중요한 변경은 앱 내 안내로 공지합니다.

Privacy Policy — GeosilGostop

Last updated: May 10, 2026

GeosilGostop ("the App") respects your privacy. The App connects only over peer-to-peer Wi-Fi/Bluetooth within range of nearby devices and does not transmit any user data to remote servers operated by the developer.

1. Data We Process

ItemWhereExternal transmission
Player nickname (user-entered)iOS UserDefaultsVisible only to peers in the same game room over P2P
Game state (hand, score)MemorySynced only with peers in the same room
iOS device ID (MCPeerID display name)MemoryBriefly visible to nearby devices on the same Wi-Fi/Bluetooth

2. Data We Do Not Collect

  • Email, phone, address — never collected.
  • Location, photos, contacts — permissions are never requested.
  • Advertising IDs (IDFA), tracking data — not used.
  • Payment data — the app has no in-app purchases.

3. No External Transmission

The app sends no data to any analytics service, ad network, or cloud server. All gameplay happens directly between peers on the same local network.

4. Local Network Permission

iOS requests Local Network permission to discover nearby devices. We use this only to find other GeosilGostop instances on the same Wi-Fi.

5. Security

P2P traffic uses Apple's Multipeer Connectivity default encryption (encryptionPreference: .required).

6. Children's Privacy

The app does not collect personal data from children under 13. There is no chat or external communication; the app is suitable for the 4+ rating.

7. Changes

This policy may be updated when functionality changes; significant changes will be announced in-app.
