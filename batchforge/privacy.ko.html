BatchForge 개인정보처리방침

BatchForge는 개인정보를 수집·저장·전송하지 않습니다.

1. 수집하는 정보

없습니다. 회원 가입·로그인·분석 도구·광고가 없습니다.

2. 이미지 파일

앱은 사용자가 워크플로에 넣은 폴더·파일의 이미지만 읽고, 사용자가 정한 출력 폴더에만 결과를 씁니다. 원본 파일은 덮어쓰지 않습니다. 이미지는 모두 사용자 PC 안에서 처리하며 어디에도 올리지 않습니다.

사진 메타데이터(위치 정보를 포함한 EXIF, 색 프로필)는 사용자의 워크플로 설정대로만 출력 파일에 옮기거나 지우거나 씁니다. 이 역시 모두 사용자 PC 안에서 이루어집니다.

3. 네트워크 사용

Pro 애드온 라이선스를 확인하고 구매할 때 Microsoft Store 서비스에 연결합니다. 결제·계정 정보는 Microsoft가 처리하며 개발자는 받지 않습니다. Microsoft 개인정보처리방침

4. 기기에 저장하는 정보

다음은 사용자 PC의 %LOCALAPPDATA%\BatchForge\에만 저장됩니다.

  • settings.json: 화면 언어, 최근 연 워크플로 파일 목록, 실행 창 설정
  • license.dat: 오프라인 사용을 위한 마지막 Pro 확인 상태(현재 Windows 사용자 기준으로 암호화)
  • Samples: 기본 예제용으로 앱이 만든 표본 이미지

워크플로 파일(.bfw)은 사용자가 고른 위치에만 저장됩니다. 이 정보는 어디로도 보내지 않습니다.
