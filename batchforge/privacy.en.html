BatchForge Privacy Policy

BatchForge does not collect, store or transmit personal information.

1. Information collected

None. There is no sign-up, login, analytics or advertising.

2. Image files

The app only reads images from the folders and files the user adds to a workflow, and writes results only to the output folders the user sets. Original files are never overwritten. Images are processed entirely on the user's PC and are never uploaded.

Photo metadata (EXIF, including any location data, and color profiles) is copied, removed or written in the output files only as the user's workflow specifies. This also happens entirely on the user's PC.

3. Network use

The app contacts Microsoft Store services to check and purchase the Pro add-on license. Payment and account data are handled by Microsoft and are not received by the developer. Microsoft Privacy Statement

4. Local storage

The following are stored only on the user's PC under %LOCALAPPDATA%\BatchForge\:

  • settings.json: display language, recently opened workflow files, and run window preferences
  • license.dat: the last verified Pro status, for offline use (encrypted for the current Windows user)
  • Samples: sample images generated by the app for the built-in examples

Workflow files (.bfw) are saved only where the user chooses. None of this is sent anywhere.
