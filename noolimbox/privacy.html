NoolimBox 개인정보처리방침

최종 업데이트: 2026-06-04 · 운영자: blue-code · 문의: digimaru@gmail.com

요약: NoolimBox는 광고 추적을 하지 않으며, 개인정보를 제3자에게 판매하지 않습니다. 계좌 금액·리스크 설정 등 민감 정보는 기본적으로 기기에만 저장되며, 증권사 API 키는 기기 Keychain과 사용자 본인이 지정한 백엔드 프록시에만 저장됩니다(평문 보관 안 함).

1. 수집·이용하는 정보

  • 계좌 설정값(평가금액, 리스크 비율, 필터 기본값) — 권장 수량(2% 룰) 계산용. 기기 로컬 저장.
  • 관심 종목 · 매수박스 · 손절선 — 워치리스트/알림 기능용. 기기 및(연동 시) 사용자 지정 백엔드에 저장.
  • 한국투자증권(KIS) Open API 앱키·시크릿·계좌번호 — 사용자가 직접 입력. 기기 Keychain 및 사용자 백엔드 프록시에만 저장. 운영자 서버로 전송되지 않습니다.
  • 푸시 알림 토큰(APNs) — 매수박스 진입/손절선 이탈/후보 알림 전송용(알림 사용 시).
  • 진단 로그 — 앱 안정성 개선을 위한 기기 내 로그(외부 전송 없음).

2. 수집하지 않는 정보

이름·연락처·위치·연락처 목록·광고 식별자(IDFA)를 수집하지 않습니다. 제3자 광고 SDK를 사용하지 않습니다.

3. 외부 데이터 출처

시세·일봉·수급은 한국투자증권 Open API, 공시는 금융감독원 DART, 뉴스는 검색 링크를 통해 제공되며, 앱은 해당 정보를 표시할 뿐 내용을 해석하거나 매매를 실행하지 않습니다.

4. 저장 및 보안

증권 API 자격증명은 iOS Keychain과 사용자가 지정한 백엔드에만 저장됩니다. 통신은 HTTPS로 암호화됩니다. 앱은 자동매매(주문 실행) 기능을 제공하지 않습니다.

5. 제3자 제공

법령에 의한 경우를 제외하고 개인정보를 제3자에게 제공·판매하지 않습니다.

6. 이용자 권리

설정에서 저장된 값을 언제든 수정·삭제할 수 있으며, 앱 삭제 시 기기 내 데이터가 제거됩니다.

7. 면책

NoolimBox는 투자 정보 제공 도구이며 투자 권유가 아닙니다. 종목 추천·수익 보장을 하지 않으며, 모든 투자 판단과 책임은 이용자에게 있습니다. 과거 성과가 미래 수익을 보장하지 않습니다.

8. 변경

본 방침은 변경될 수 있으며, 변경 시 본 페이지를 통해 고지합니다.
