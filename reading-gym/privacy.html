리딩짐 — 개인정보처리방침

최종 업데이트: 2026-05-09

1. 수집하는 정보

리딩짐(이하 “앱”)은 사용자의 개인 식별 정보(이름, 이메일, 전화번호, 위치 등)를 수집하지 않습니다. 사용자는 별도 가입이나 로그인 없이 앱을 사용합니다.

1.1 기기 내부에만 저장되는 정보

항목용도저장 위치
훈련 기록 (속도, 이해도, 점수, 일시)통계와 진척도 표시기기 내부 SwiftData / 사용자 설정
레벨, 경험치, 연속 일수진척 시각화기기 내부
읽기 환경 설정 (글자 크기 등)UI 설정기기 내부 (UserDefaults)
일일 무료 훈련 토큰 사용 일자무료/PRO 구분기기 내부 (UserDefaults)

위 데이터는 사용자의 기기 안에만 저장되며, 외부 서버로 전송되지 않습니다.

1.2 Apple이 처리하는 정보

인앱 결제(PRO)는 Apple StoreKit을 통해서만 처리됩니다. 결제와 관련된 모든 정보는 Apple이 직접 처리하며, 본 앱은 결제 정보를 수집하거나 저장하지 않습니다. Apple의 정책은 apple.com/legal/privacy를 참고하세요.

2. 외부 전송 / 분석 도구

본 앱은 광고 SDK, 분석 도구, 트래커를 사용하지 않습니다. 사용자의 행동 데이터는 외부로 전송되지 않습니다.

3. 어린이 정보

본 앱은 13세 미만 어린이를 직접 대상으로 하지 않으며, 의도적으로 어린이의 개인정보를 수집하지 않습니다.

4. 데이터 삭제

모든 사용자 데이터는 기기에만 저장되므로, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다. 별도의 삭제 요청 절차가 필요하지 않습니다.

5. 변경 사항

본 방침이 변경되면 이 페이지에 게시됩니다. 중요한 변경이 있을 경우 앱 내 공지로도 안내합니다.

リーディングジム — プライバシーポリシー

最終更新: 2026-05-09

1. 収集する情報

リーディングジム(以下「本アプリ」)は、氏名・メールアドレス・電話番号・位置情報などの個人識別情報を収集しません。アカウント登録やログインも不要です。

1.1 端末内にのみ保存される情報

  • トレーニング記録(速度、理解度、スコア、日時)— SwiftData/UserDefaults
  • レベル、XP、連続日数 — 端末内
  • 読書設定(文字サイズ等)— UserDefaults
  • 無料トレーニングトークンの使用日 — UserDefaults

これらのデータは端末内にのみ保存され、外部に送信されません。

1.2 Appleが処理する情報

アプリ内課金(PRO)はApple StoreKit経由で処理されます。本アプリは決済情報を収集・保存しません。詳しくはapple.com/legal/privacyをご覧ください。

2. 第三者トラッカー

本アプリは広告SDK、分析SDK、トラッカーを使用しません。

3. 子どものプライバシー

本アプリは13歳未満の子どもを対象としておらず、子どもの個人情報を意図的に収集しません。

4. データ削除

すべてのユーザーデータは端末内に保存されているため、アプリを削除すれば全データが削除されます。

5. 変更

本ポリシーが変更された場合、このページに掲載します。

6. お問い合わせ

お問い合わせ: digimaru@gmail.com

阅读健身房 — 隐私政策

最后更新: 2026-05-09

1. 我们收集的信息

阅读健身房(以下简称"本应用")不收集姓名、邮箱、电话、位置等个人识别信息,也不需要注册或登录。

1.1 仅存储在设备上

  • 训练记录(速度、理解度、分数、时间)— 本地 SwiftData/UserDefaults
  • 等级、XP、连续天数 — 本地
  • 阅读偏好(字号等)— UserDefaults
  • 免费训练令牌使用日期 — UserDefaults

上述数据仅保存在您的设备上,不会上传到任何服务器。

1.2 由 Apple 处理的信息

应用内购买(PRO)完全通过 Apple StoreKit 处理。本应用不收集或存储任何支付信息。详见apple.com/legal/privacy。

2. 第三方跟踪器

本应用不包含广告 SDK、分析 SDK 或跟踪器。

3. 儿童隐私

本应用不面向 13 岁以下儿童,也不会有意收集儿童的个人信息。

4. 数据删除

所有用户数据均存储在设备上。删除应用即可删除所有数据。

5. 变更

本政策若有变更,将在本页面更新。
