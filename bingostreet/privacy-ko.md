# 개인정보처리방침 — 빙고 스트릿 (Bingo Street)

**시행일: 2026년 5월 26일**

빙고 스트릿(이하 "본 앱")은 회원가입 없이 즉시 시작할 수 있는 위치 기반 사진 빙고 게임입니다. 본 앱은 이용자의 개인정보를 수집하지 않는 것을 기본 원칙으로 설계되었습니다. 본 처리방침은 본 앱이 어떤 정보를 다루고, 어떻게 보호하는지를 설명합니다.

## 1. 수집하는 정보

본 앱은 회원가입을 요구하지 않으며, 운영자(개발자)는 이용자를 식별할 수 있는 어떠한 개인정보도 수집하지 않습니다. 본 앱에서 다루는 데이터는 다음과 같으며, 별도로 명시하지 않는 한 모두 이용자의 기기 내에만 저장됩니다.

| 항목 | 처리 위치 | 목적 | 서버 전송 |
|------|-----------|------|-----------|
| 인증 사진 | 기기 내부(앱 샌드박스) | 빙고 칸 인증·기록 | 전송하지 않음 |
| 위치 정보(선택) | 사진 메타데이터에 포함될 수 있음 | 기록 화면 표시용 | 전송하지 않음 |
| 닉네임·이니셜·색상 | 기기 내부 | 프로필·멀티플레이 표시 | 근거리 기기에만 표시(아래 4항) |
| 게임 기록(보드·결과·시간) | 기기 내부(SwiftData) | 내 기록 열람 | 전송하지 않음 |
| 크래시 로그 | Apple | 안정성 개선 | Apple 표준·비식별(아래 5항) |

본 앱은 이름, 이메일, 전화번호, 광고 식별자, 트래킹 식별자를 수집하지 않습니다.

## 2. 정보의 이용

- **인증 사진**은 빙고 칸을 채우고 결과·기록 화면에 표시하는 용도로만 사용됩니다.
- **위치 정보**는 사진을 촬영할 때 사진 메타데이터(EXIF)에 포함될 수 있으며, 오직 기기 내 기록 상세 화면에서 "어디서 찍었는지"를 보여주기 위한 용도로만 사용됩니다. 운영자 서버로 전송되지 않습니다.
- **프로필 정보(닉네임·이니셜·색상)**는 게임 화면과 근거리 멀티플레이에서 참가자를 구분하기 위해 사용됩니다.
- 수집되는 정보는 광고, 마케팅, 프로파일링, 모델 학습 등 어떠한 다른 목적으로도 사용되지 않습니다.

## 3. 제3자 제공 (없음)

본 앱은 이용자의 데이터를 제3자에게 제공·판매·공유하지 않습니다. 본 앱은 인증·계정 서버, 분석(애널리틱스) SDK, 광고 네트워크, 트래킹 SDK를 사용하지 않습니다. 앱이 수집한 사진·위치·기록은 운영자를 포함한 외부로 전송되지 않습니다.

예외적으로 Apple은 운영체제 차원에서 표준 크래시/진단 로그를 처리할 수 있으며(아래 5항), 이는 비식별 정보입니다.

## 4. 근거리 멀티플레이 (MultipeerConnectivity)

멀티플레이는 인터넷 서버나 중앙 계정 없이, Apple의 MultipeerConnectivity 프레임워크를 통해 근거리 통신(Bluetooth / Wi-Fi)으로만 이루어집니다.

- 같은 게임에 참여한 **근처 기기들 사이에서만** "누가 어떤 칸을 채웠는지"와 같은 게임 상태가 동기화됩니다.
- 프로필 표시 정보(닉네임·이니셜·색상)는 같은 게임의 근거리 참가자에게 표시됩니다.
- **인증 사진 원본은 다른 기기로 전송되지 않습니다.**
- 모든 통신은 동일 근거리 네트워크 범위 내에서만 발생하며, 외부 서버를 경유하지 않습니다.

## 5. 크래시 로그

이용자가 Apple 기기 설정에서 진단 데이터 공유에 동의한 경우, Apple이 표준 크래시·진단 로그를 운영자에게 제공할 수 있습니다. 이 로그는 비식별 정보이며 안정성 개선 목적에만 사용됩니다. 해당 데이터의 처리는 Apple의 [개인정보 보호정책](https://www.apple.com/legal/privacy/)을 따릅니다.

## 6. 데이터 보관 및 삭제

- 사진·기록·프로필 등 본 앱의 모든 데이터는 이용자의 기기 내에만 저장됩니다.
- 앱 내 기록 상세 화면에서 개별 게임 기록을 삭제할 수 있습니다.
- **앱을 삭제하면** 본 앱이 저장한 모든 로컬 데이터(사진·기록·프로필 포함)가 기기에서 함께 제거됩니다.
- 운영자 서버에는 이용자 데이터가 저장되지 않으므로 별도의 서버 삭제 요청 절차가 필요하지 않습니다.

## 7. 권한 (Permissions)

| 권한 | 필수 여부 | 사용 목적 |
|------|-----------|-----------|
| 카메라(`NSCameraUsageDescription`) | 필수 | 빙고 칸 인증 사진을 직접 촬영 |
| 위치(선택) | 선택 | 사진 메타데이터에 위치를 기록(기록 화면 표시용) |
| 로컬 네트워크(`NSLocalNetworkUsageDescription`) | 멀티플레이 시 | 근거리 기기 탐색·연결(MultipeerConnectivity) |

본 앱은 **사진 보관함(갤러리) 접근 권한을 요청하지 않습니다.** 인증은 직접 촬영으로만 이루어지며, 갤러리에서 사진을 불러오지 않습니다. 권한은 기기 설정에서 언제든지 변경할 수 있으며, 카메라 권한이 없으면 사진 인증 기능을 사용할 수 없습니다.

## 8. 아동의 개인정보

본 앱의 연령 등급은 4+이며, 어린이를 포함한 모든 연령대가 안전하게 사용할 수 있도록 어떠한 개인정보도 수집하지 않습니다. 본 앱은 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.
