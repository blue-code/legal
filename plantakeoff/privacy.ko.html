PlanTakeoff 개인정보처리방침

PlanTakeoff는 개인정보를 수집·저장·전송하지 않습니다. 인터넷 연결 없이 동작합니다.

1. 수집하는 정보

없습니다. 회원 가입·로그인·분석 도구·광고가 없고, 앱은 인터넷에 연결하지 않습니다.

2. 도면과 프로젝트

앱은 사용자가 연 PDF·DXF 도면만 읽습니다. 원본 도면 파일은 바꾸지 않습니다. 도면 사본은 프로젝트 파일(.ptk) 안에 보관되며, 프로젝트 파일은 사용자가 고른 위치에만 저장됩니다. 도면은 모두 사용자 PC 안에서 처리하고(해석은 같은 PC의 별도 프로세스에서 합니다) 어디에도 올리지 않습니다.

PDF·Excel·CSV로 내보낸 견적서는 사용자가 고른 위치에만 저장됩니다.

3. 구매와 체험판

구매와 무료 체험은 Microsoft Store가 처리합니다. 결제·계정 정보는 Microsoft가 처리하며 개발자는 받지 않습니다. Microsoft 개인정보처리방침

4. 기기에 저장하는 정보

다음은 사용자 PC의 %LOCALAPPDATA%\PlanTakeoff\에만 저장됩니다.

  • settings.json: 화면 언어, 테마, 단위, 기본 통화·세율·로스율, 최근 연 프로젝트, 견적서에 찍을 업체 정보(상호·연락처·로고)
  • catalog.json: 사용자가 만든 단가 카탈로그
  • Recovery: 저장하지 않은 프로젝트의 자동 복구 사본(정상적으로 닫으면 지워짐)

도면 임시 작업 사본은 앱을 끝낼 때 지웁니다. 이 정보는 어디로도 보내지 않습니다.
