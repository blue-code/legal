PlanTakeoff Privacy Policy

PlanTakeoff does not collect, store or transmit personal information. It works entirely offline.

1. Information collected

None. There is no sign-up, login, analytics or advertising, and the app does not connect to the internet.

2. Drawings and projects

The app only reads the PDF and DXF drawings the user opens. Original drawing files are never modified. A copy of each drawing is kept inside the project file (.ptk), which is saved only where the user chooses. Drawings are processed entirely on the user's PC — parsing runs in a separate process on the same PC — and are never uploaded.

Estimates exported as PDF, Excel or CSV are written only to the location the user chooses.

3. Purchases and trials

Purchases and free trials are handled by the Microsoft Store. Payment and account data are processed by Microsoft and are not received by the developer. Microsoft Privacy Statement

4. Local storage

The following are stored only on the user's PC under %LOCALAPPDATA%\PlanTakeoff\:

  • settings.json: display language, theme, units, default currency and rates, recently opened projects, and the company details (name, contact, logo) the user enters to print on estimates
  • catalog.json: the user's own price catalog
  • Recovery: automatic recovery copies of unsaved projects, deleted when a project is closed normally

Temporary working copies of drawings are deleted when the app exits. None of this is sent anywhere.
