Strata 지원

디스크를 채우고 있는 것을 중첩 지도로 찾아내는 맥 앱입니다.

자주 묻는 것

디스크를 고를 때 macOS가 권한을 묻습니다

Strata는 App Sandbox 안에서 동작하므로, 사용자가 표준 권한 창에서 직접 고른 위치만 읽을 수 있습니다. 한 번만 물으며, 그 뒤로는 시작 화면의 디스크 카드를 눌러 바로 스캔됩니다(파란 화살표 표시).

일부 폴더를 읽지 못했다고 나옵니다

권한이 없는 폴더는 건너뜁니다. 해당 폴더를 직접 골라 다시 스캔하면 포함됩니다.

Finder에 표시되는 용량과 다릅니다

Strata는 파일이 실제로 디스크에서 차지하는 점유 크기를 씁니다. APFS 클론이나 sparse 파일은 논리 크기와 점유 크기가 다를 수 있습니다.

삭제하면 완전히 지워지나요?

아닙니다. 항상 휴지통으로 이동합니다. 영구 삭제 기능은 앱에 없습니다.

필터를 어떻게 쓰나요?

툴바의 슬라이더 버튼을 누르면 종류·크기·기간·태그를 골라 만들 수 있습니다. 직접 입력할 수도 있습니다: *.mp4;>500mb;>2years — 같은 종류끼리는 OR, 다른 종류끼리는 AND입니다.

결제한 기능이 안 보입니다

설정(⌘,) → Strata Pro → 구매 복원을 눌러 주세요.

문의

버그나 제안은 앱의 설정 → 정보 → 피드백 보내기로 보내 주세요. 앱 버전과 사용 언어가 자동으로 함께 전달됩니다.

Strata Support

A Mac app that finds what is filling your disk, using a nested map.

Common questions

macOS asks for permission when I pick a disk

Strata runs inside the App Sandbox, so it can only read locations you choose yourself in the standard permission dialog. It asks once; after that, clicking the disk card on the welcome screen scans it straight away (shown with a blue arrow).

It says some folders couldn't be read

Folders you haven't granted access to are skipped. Choose that folder directly and scan again to include it.

The size differs from what Finder shows

Strata uses allocated size — the space a file actually occupies on disk. APFS clones and sparse files can have a logical size that differs from what they really take up.

Does deleting remove files permanently?

No. Strata always moves to the Trash. There is no permanent-delete feature in the app.

How do filters work?

Press the slider button in the toolbar to build one from kind, size, age and tags. You can also type one: *.mp4;>500mb;>2years — terms of the same kind are OR'd, different kinds are AND'd.

I paid but the features are locked

Open Settings (⌘,) → Strata Pro → Restore Purchase.

Contact

Send bugs and suggestions from Settings → About → Send Feedback in the app. Your app version and language are included automatically.

Privacy Policy

Strata サポート

ディスクを埋めているものを入れ子のマップで見つける Mac アプリです。

ディスクを選ぶと macOS が許可を求めます

Strata は App Sandbox 内で動作するため、標準の許可ダイアログでユーザーが選んだ場所のみ読み取れます。確認は初回のみで、その後はようこそ画面のディスクカードを押せばすぐスキャンされます（青い矢印表示）。

一部のフォルダを読めなかったと出ます

権限のないフォルダはスキップします。そのフォルダを直接選んで再スキャンすれば含まれます。

Finder の表示と容量が違います

Strata は実際にディスクを占有する割り当てサイズを使います。APFS クローンやスパースファイルは論理サイズと異なることがあります。

削除すると完全に消えますか

いいえ。常にゴミ箱へ移動します。完全削除の機能はありません。

購入した機能が使えません

設定(⌘,) → Strata Pro → 購入を復元を押してください。

お問い合わせ

アプリの設定 → 情報 → フィードバックを送るからお送りください。

プライバシーポリシー

Strata 支持

用嵌套地图找出占满磁盘的元凶的 Mac 应用。

选择磁盘时 macOS 请求授权

Strata 运行于 App Sandbox 内，只能读取你在标准授权对话框中亲自选择的位置。只会询问一次，之后点击欢迎界面的磁盘卡片即可直接扫描（显示蓝色箭头）。

提示有些文件夹无法读取

未获授权的文件夹会被跳过。直接选择该文件夹重新扫描即可包含。

容量和访达显示的不一样

Strata 使用实际占用大小。APFS 克隆和稀疏文件的逻辑大小可能与实际占用不同。

删除会永久清除吗

不会。始终移到废纸篓。应用中没有永久删除功能。

已购买但功能仍锁定

设置(⌘,) → Strata Pro → 恢复购买。

联系我们

请通过应用内设置 → 关于 → 发送反馈联系。

隐私政策

Strata 支援

用巢狀地圖找出佔滿磁碟元凶的 Mac App。

選擇磁碟時 macOS 要求授權

Strata 執行於 App Sandbox 內，只能讀取你在標準授權對話框中親自選擇的位置。只會詢問一次，之後點擊歡迎畫面的磁碟卡片即可直接掃描（顯示藍色箭頭）。

顯示有些檔案夾無法讀取

未獲授權的檔案夾會被略過。直接選擇該檔案夾重新掃描即可包含。

容量與 Finder 顯示不同

Strata 使用實際佔用大小。APFS 複製與稀疏檔案的邏輯大小可能與實際佔用不同。

刪除會永久清除嗎

不會。始終移到垃圾桶。App 中沒有永久刪除功能。

已購買但功能仍鎖定

設定(⌘,) → Strata Pro → 回復購買。

聯絡我們

請透過 App 內設定 → 關於 → 傳送意見回饋聯絡。
