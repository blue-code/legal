Strata는 어떤 개인정보도 수집하지 않습니다. 네트워크 요청을 하지 않으며, 분석 도구나 계정이 없고, 기기 밖으로 나가는 데이터가 없습니다.

수집하는 정보

없습니다. Strata는 서버와 통신하지 않습니다. 앱에는 네트워크 코드 자체가 들어 있지 않으며, 이는 소스 검사 테스트로 강제됩니다.

파일 접근

Strata는 App Sandbox 안에서 동작하며, macOS 표준 권한 창을 통해 사용자가 직접 고른 디스크와 폴더만 읽습니다. 파일 내용을 읽지 않고 이름·크기·수정일만 봅니다. 시스템 보호 경로는 거부합니다.

삭제

Strata의 삭제는 항상 휴지통으로 이동입니다. 영구 삭제 경로는 앱에 존재하지 않습니다.

결제

Strata Pro 결제는 Apple의 App Store를 통해 처리되며 Strata는 결제 정보를 보거나 저장하지 않습니다.

Strata Privacy Policy

Strata collects nothing. It makes no network requests, has no analytics and no account, and no data ever leaves your device.

What we collect

Nothing. Strata never talks to a server. The app contains no networking code at all, and a source-scanning test enforces that.

What is stored on your Mac

ItemWhereWhy
Access to folders you scanned (security-scoped bookmarks)App containerSo you don't re-pick the folder every launch
Four-colour tagsApp containerRemember what you marked
Display preferencesApp containerShow hidden files, etc.

All of it stays on your Mac and is removed when you delete the app.

File access

Strata runs inside the App Sandbox and reads only the disks and folders you explicitly choose through the standard macOS permission dialog. It reads names, sizes and modification dates — never file contents. Protected system paths are refused.

Deletion

Deleting in Strata always moves to the Trash. There is no permanent-delete code path in the app.

Payments

Strata Pro is purchased through Apple's App Store. Strata never sees or stores payment details.
