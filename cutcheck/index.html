Start with Import Matrix and choose a UTF-8 CSV. Map Variant, Market, Aspect (W:H) and Duration (seconds), then Apply Mapping. Use a decimal dot, such as 2.5 seconds, and an aspect like 16:9. Save Preset stores the column mapping for this client; it does not rename or translate client data.

Optional fields include exact relative filename, dimensions, nominal frame rate, codec, audio, channel count, sample rate and a copy note. Audio values in the CSV must be required, none or any in every UI language. A channel or sample-rate requirement implies audio must exist. Channel requirements apply to every audio track.

Choose Folder or drop a local export folder. MOV, MP4 and M4V files in subfolders are included. Matching uses delimited variant and market tokens, plus optional 16x9 and 15s filename labels. Set exact relative filenames for ambiguous names. Run Checks reads actual AVFoundation metadata. Rerun Checks reads the folder again after you replace files.

Review findings for missing, duplicate, ambiguous, unmatched, unreadable and technical mismatches. Text, language, legal lines, loudness, picture/sound quality and every-frame integrity always need human review. This tool does not certify client approval. Export Handoff saves a standard CSV report, free and repeatable. Choose Report language separately from UI language: English, US Spanish, French or German. Original filenames, column names and client values remain unchanged. CSV cells that could trigger spreadsheet formulas are prefixed for safety.
