Privacy Policy — NexTerm

Effective: September 29, 2026 · Last updated: September 29, 2026

Summary: NexTerm is a Windows desktop app with no backend server of its own. Settings, workspace layout, and terminal session content are stored and processed only on your PC. There is no analytics, advertising, or tracking SDK, and no user data is ever sent to blue-code's servers.

1. Information We Collect and Store

NexTerm never sends your data to an external server. The following is stored only on your PC's local storage.

  • App settings — font, theme, default shell, etc. (%APPDATA%/nexterm/settings.json)
  • Session state — workspace/panel layout (%APPDATA%/nexterm/session.json, auto-expires after 24 hours)
  • Saved favorite/quick commands — a local list of frequently used terminal commands you register
  • Terminal session content — commands you type and their output are processed only through a local process (node-pty) and are never transmitted anywhere.

2. Third-Party Disclosure and Sharing

NexTerm does not disclose or share any user data with third parties.

  • No analytics tools
  • No crash-reporting SDK
  • No advertising or tracking identifiers
  • No backend server of its own

3. AI Agent Usage Lookup (Optional Feature)

NexTerm includes an optional feature that shows usage/quota for CLI-based AI coding tools such as Claude Code, Codex, and Antigravity in the status bar.

  • This feature reads the credentials (OAuth tokens, etc.) that you have already stored locally by signing in to those CLI tools yourself, and sends the lookup request directly from your PC to each provider's official API (Anthropic, OpenAI, Google).
  • These requests and responses never pass through any blue-code server, and NexTerm does not separately collect, store, or transmit these credentials.
  • This feature can be turned off at any time in Settings.

4. Permissions

NexTerm uses the following local capabilities, all of which operate only on your device.

  • File system access — opening a folder you specify, or launching via the Explorer right-click menu ("Open with NexTerm")
  • Clipboard read/write — terminal copy (Ctrl+Shift+C) and paste (Ctrl+V)
  • Local process execution — running PowerShell, Command Prompt, or shells/CLI tools you have installed

5. Data Retention and Deletion

Deleting the %APPDATA%/nexterm folder removes all local data, including settings and session state.

6. Accounts and Sign-in

NexTerm itself does not require account creation or sign-in.

7. Automatic Updates

The standard distribution checks the GitHub Releases API only to see whether a newer version exists, and transmits no personally identifiable information. The Microsoft Store build uses the Store's own update mechanism, and this feature is disabled in that build.

8. Children's Privacy

NexTerm is not directed at children under 13 and does not knowingly collect information from children.

9. Changes to This Policy

If this policy changes, updates and the effective date will be posted on this page.
