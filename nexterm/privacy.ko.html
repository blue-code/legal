개인정보처리방침 — NexTerm

시행일: 2026년 9월 29일 · 최종 업데이트: 2026년 9월 29일

요약: NexTerm은 별도의 백엔드 서버를 운영하지 않는 Windows 데스크톱 앱입니다. 설정, 작업 영역 레이아웃, 터미널 세션 내용은 모두 사용자 PC 내부에만 저장·처리됩니다. 분석/광고/트래킹 SDK가 전혀 없으며, blue-code 서버로 어떠한 사용자 데이터도 전송되지 않습니다.

1. 수집·저장하는 정보

NexTerm은 사용자 데이터를 외부 서버로 전송하지 않습니다. 다음 정보는 모두 사용자 PC의 로컬 저장소에만 보관됩니다.

  • 앱 설정 — 글꼴, 테마, 셸 종류 등의 환경설정 (%APPDATA%/nexterm/settings.json)
  • 세션 상태 — 작업 영역/패널 레이아웃 (%APPDATA%/nexterm/session.json, 24시간 후 자동 만료)
  • 사용자가 등록한 즐겨찾기·빠른 명령어 — 터미널에서 자주 쓰는 명령을 로컬에 저장한 목록
  • 터미널 세션 내용 — 사용자가 입력한 명령과 그 출력 결과는 로컬 프로세스(node-pty)를 통해서만 처리되며, 어디로도 전송되지 않습니다.

2. 제3자 제공 및 공유

NexTerm은 어떠한 사용자 데이터도 제3자에게 제공하거나 공유하지 않습니다.

  • 분석(Analytics) 도구 없음
  • 크래시 리포팅 SDK 없음
  • 광고 또는 트래킹 식별자 미사용
  • 자체 백엔드 서버 운영 안 함

3. AI 에이전트 사용량 조회 (선택 기능)

NexTerm에는 Claude Code, Codex, Antigravity 등 CLI 기반 AI 코딩 도구의 사용량(쿼터)을 상태 표시줄에 보여주는 선택적 기능이 있습니다.

  • 이 기능은 사용자가 이미 해당 CLI 도구에 로그인하여 PC에 저장해 둔 인증 정보(OAuth 토큰 등)를 읽어, 사용자의 PC에서 직접 Anthropic·OpenAI·Google 등 각 서비스의 공식 API로 조회 요청을 보냅니다.
  • 이 요청과 응답은 blue-code 서버를 거치지 않으며, NexTerm은 해당 인증 정보를 별도로 수집·저장·전송하지 않습니다.
  • 이 기능은 설정에서 언제든 끌 수 있습니다.

4. 권한 안내

NexTerm은 다음 로컬 기능을 사용하며, 모두 사용자 기기 내에서만 동작합니다.

  • 파일 시스템 접근 — 사용자가 지정한 작업 폴더를 열람하거나 탐색기 우클릭 메뉴("NexTerm으로 열기")로 실행
  • 클립보드 읽기/쓰기 — 터미널 복사(Ctrl+Shift+C)·붙여넣기(Ctrl+V) 기능
  • 로컬 프로세스 실행 — PowerShell/명령 프롬프트/사용자가 설치한 셸 및 CLI 도구 실행

5. 데이터 보관 및 삭제

%APPDATA%/nexterm 폴더를 삭제하면 설정과 세션을 포함한 모든 로컬 데이터가 제거됩니다.

6. 계정 및 로그인

NexTerm 자체는 회원가입이나 로그인을 요구하지 않습니다.

7. 자동 업데이트

일반 배포판은 GitHub Releases API를 통해 새 버전 존재 여부만 확인하며, 개인 식별 정보를 전송하지 않습니다. Microsoft Store 배포판은 Store 자체 업데이트 메커니즘을 사용하며 이 기능이 비활성화되어 있습니다.

8. 아동의 개인정보

NexTerm은 만 13세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 정보를 수집하지 않습니다.

9. 처리방침의 변경

본 처리방침이 변경될 경우 본 페이지에 변경 사항과 시행일을 게시합니다.
