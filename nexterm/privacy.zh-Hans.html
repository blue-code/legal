隐私政策 — NexTerm

生效日期：2026年9月29日 · 最近更新：2026年9月29日

摘要：NexTerm 是一款没有自有后端服务器的 Windows 桌面应用。设置、工作区布局和终端会话内容仅保存和处理在您的电脑本地。应用不含任何分析、广告或跟踪 SDK，也不会向 blue-code 的服务器发送任何用户数据。

1. 收集与存储的信息

NexTerm 不会将您的数据发送到外部服务器。以下信息仅保存在您电脑的本地存储中。

  • 应用设置 — 字体、主题、默认 Shell 等（%APPDATA%/nexterm/settings.json）
  • 会话状态 — 工作区／面板布局（%APPDATA%/nexterm/session.json，24 小时后自动过期）
  • 用户保存的常用／快捷命令 — 本地保存的常用终端命令列表
  • 终端会话内容 — 您输入的命令及其输出仅通过本地进程（node-pty）处理，绝不会被发送到任何地方。

2. 第三方提供与共享

NexTerm 不会将任何用户数据提供或共享给第三方。

  • 无分析（Analytics）工具
  • 无崩溃报告 SDK
  • 不使用广告或跟踪标识符
  • 不运营自有后端服务器

3. AI 代理用量查询（可选功能）

NexTerm 提供一个可选功能，可在状态栏显示 Claude Code、Codex、Antigravity 等基于 CLI 的 AI 编程工具的用量（配额）。

  • 该功能会读取您已自行登录相应 CLI 工具并保存在本机的凭据（如 OAuth 令牌），并直接从您的电脑向 Anthropic、OpenAI、Google 等各服务商的官方 API 发送查询请求。
  • 这些请求与响应不会经过 blue-code 的任何服务器，NexTerm 也不会另行收集、存储或传输这些凭据。
  • 您可以随时在设置中关闭此功能。

4. 权限说明

NexTerm 使用以下本地功能，均仅在您的设备上运行。

  • 文件系统访问 — 打开您指定的工作文件夹，或通过资源管理器右键菜单（"使用 NexTerm 打开"）启动
  • 剪贴板读写 — 终端复制（Ctrl+Shift+C）／粘贴（Ctrl+V）
  • 本地进程执行 — 运行 PowerShell、命令提示符或您已安装的 Shell／CLI 工具

5. 数据保留与删除

删除 %APPDATA%/nexterm 文件夹即可清除包括设置和会话状态在内的所有本地数据。

6. 账户与登录

NexTerm 本身不需要注册账户或登录。

7. 自动更新

标准发行版仅通过 GitHub Releases API 检查是否存在新版本，不传输任何可识别个人身份的信息。Microsoft Store 版本使用 Store 自身的更新机制，该功能在此版本中已被禁用。

8. 儿童隐私

NexTerm 不面向 13 岁以下儿童，也不会故意收集儿童的信息。

9. 政策变更

如本政策发生变更，变更内容及生效日期将公布在本页面。
